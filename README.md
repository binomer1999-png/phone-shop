# موقع الشريف للموبايلات

موقع بسيط للمحل: الزبون يشوف الموبايلات والأسعار، يحجز أي موبايل بضغطة (بتفتح واتساب برسالة جاهزة فيها اسم الموبايل)، أو يكلم المحل واتساب مباشرة.

الأسعار المعروضة استرشادية "تبدأ من"، متجمعة من دريم ستورز (dreamstores-eg.com) ودريم 2000 (dream2000.com) بتاريخ 27 نوفمبر 2026.

## التعديل

كل حاجة من ملف واحد: `index.html`.

- **اسم المحل / رقم الواتساب / العنوان / المواعيد:** في بلوك `CONFIG` فوق في الملف.
- **المنتجات:** في قائمة `PRODUCTS` تحتها. كل منتج ليه اسم وتصنيف وإيموجي ووصف صغير وسعر.
  - `price: 15000` يظهر السعر. `price: null` يظهر "تواصل لمعرفة السعر".

بعد أي تعديل، ارفع الملف هنا تاني والموقع بيتحدث خلال دقيقة.
